# Manga Downloader Project Using `Mangadex API`

This project uses Mangadex API to download manga from the site.
It's my first project, so it's far from ideal, it's just something to learn. I don't know how long i'll keep committed to this, probably not very long, just try to fix it and sometime in the future see what I can improve.
It uses Python, so you need to install Python and it should run just fine.

As there's still much progress to be done, most functionalities should be added sometime soon.

## What Works
[ ] Search By Title
[ ] Chapter download and folder management
